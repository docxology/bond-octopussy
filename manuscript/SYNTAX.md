# Manuscript syntax reference (FABERGÉ)

This sidecar documents citation, figure, and cross-reference syntax for this
manuscript. It illustrates literal `{{VARIABLE}}` placeholders; the live
resolution is governed by `src/octopussy/manuscript_variables.py` and gated by
`tests/test_manuscript_variables.py` over the numbered `NN_*.md` sections only.

## {{VARIABLE}} tokens

Numbered sections may use any token produced by
`src/octopussy/manuscript_variables.py::generate_variables()` — e.g.
`{{FABERGE_CODENAME}}`, `{{FABERGE_SEED}}`, `{{FABERGE_FLAGGED_FORGERY}}`.
The cross-reference test fails if a numbered section uses a token that
`generate_variables()` does not emit.

## Figures

Reference generated figures with Pandoc-crossref. All render from
`src/octopussy/figures/` and are regenerated by `scripts/mission_execute.py`.

- `{@fig:forgery}` — `output/figures/forgery_fingerprints.png`
- `{@fig:rail}` — `output/figures/rail_network.png`
- `{@fig:sweep}` — `output/figures/sweep_heatmap.png`

## Citations

Use Pandoc citation syntax, e.g. `[@nasdala2004faberge]`; bib entries live in
`references.bib`.

# Standalone fork guide — Octopussy: FABERGÉ

This package is a BOND-suite film package (film *Octopussy*, 1983; mission
codename **FABERGÉ**). It is a **local-only** working tree inside
`projects/working/bond/octopussy/` with **no remote — never push**.

The package was scaffolded from `template_code_project` (see the exemplar
lineage) and converted to its FABERGÉ identity in the BOND phase-2 build, then
deepened in phase 4. It now carries **six** pure domain modules — forgery
detection and varnish ageing, cover logistics and rolling-stock circulation,
concealment sweep and radiation source localization — assembled behind the
frozen BOND-API `MissionProvider` protocol. Nothing of the exemplar's own
domain remains; only its pipeline, manuscript, and gate conventions.
